## SDE 求职辅导

我是一名有约 5 年经验的软件工程师，做过后端研发、GIS 地理空间系统、金融科技风控系统，也做过技术产品经理。我在英国读研，在海外参加过大量技术面试，熟悉企业真实的研发场景，也知道面试官想听到什么。

我的辅导重点不是背题，而是帮你**把真实做过的事讲清楚、讲出深度**。

## 服务内容

+ **简历与项目经历优化**
  找出简历里最有价值的项目，按"背景、你的角色、技术方案、结果"重写，让每一条都经得起追问。

+ **项目深挖**
  模拟面试官逐层追问你的项目：为什么这么设计？瓶颈在哪？如果数据量翻十倍怎么办？帮你提前准备好答案。

+ **系统设计面试**
  从需求澄清、容量估算、接口设计、数据模型到扩展性和取舍，带你建立一套能套用到任何题目的答题框架。

+ **模拟技术面试（Mock Interview）**
  按目标公司的面试流程完整模拟，面试结束后给你逐项的书面反馈和改进建议。

+ **技术知识体系梳理**
  针对后端、数据库、分布式、Python / Java 等方向，帮你找出知识盲区，制定复习计划。

+ **职业发展规划**
  后端、GIS、金融科技、AI 应用、技术产品，这些方向怎么选、怎么转，结合你的背景一起分析。

## 适合谁

+ 准备找 SDE / 后端开发岗位的应届生和在读硕士
+ 想从其他岗位转向软件开发的工程师
+ 有工作经验、准备跳槽，但不知道如何讲好项目的开发者
+ 对 GIS、金融科技、AI 应用方向感兴趣，想了解行业真实情况的同学

## 辅导流程

1. **发邮件预约**：附上简历和目标岗位，简单说明你目前最想解决的问题。
2. **首次沟通**：了解你的背景和目标，确定辅导重点和节奏。
3. **针对性辅导**：简历修改、项目深挖、系统设计或模拟面试，按需安排。
4. **复盘反馈**：每次辅导后给出书面反馈，标出进步和下一步要练的地方。
